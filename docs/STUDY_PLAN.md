# 学习计划（每天 3.5 小时 · 3 周压缩版）

> **目标：尽快拿到面试，并在面试里不卡壳。**
> 策略：**边投边学** —— 第 1 周就把简历投出去，不要等学完再投。

---

## ⚠️ 最重要的一条：不要等学完再投简历

从投简历到约到面试，通常要 3–7 天。如果你等 3 周学完再投，
等于白白浪费 3 周。**正确顺序是：**

```
Day 0  项目推上 GitHub + 简历写好  →  立刻可以投
Day 1  开始投简历（每天投 5–10 家）
Day 1+ 边等面试边学 —— 面试来了就是实战检验
```

**投简历不需要等"准备好"。** 你现在缺的不是知识，是把已有的东西讲清楚。

---

## 一、Day 0（今天）：先把弹药准备好

- [ ] **把项目剩余部分全部推到 GitHub**（10 分钟）
  - 现在仓库里只有骨架 + 采集层，缺可视化、分析、文档
  - 简历里写链接，面试官点开要看到一个**完整**的项目
- [ ] **写简历**（60 分钟）
  - 项目描述用 `README.md` 里的"发现"章节
  - 重点写：数据规模、技术栈、**你自己解决过什么问题**
- [ ] **注册/更新招聘平台**（30 分钟）
  - BOSS 直聘、拉勾、猎聘、脉脉
  - 岗位关键词：数据分析师、商业分析、数据运营

## 二、每天的时间预算（3.5 小时）

| 时段 | 时长 | 做什么 |
|---|---|---|
| 🔥 热身 | 15 分钟 | 重写昨天 1 道 SQL + 口述昨天业务题 |
| 📊 业务拆解 | 50 分钟 | 1 道题：自己拆 10 分钟 → 看示范 → 对比差距 |
| 🗄️ SQL | 70 分钟 | 3 道题：先写 → 看答案 → **合上答案重写** |
| ☕ 休息 | 15 分钟 | 真休息 |
| 💻 项目代码 | 50 分钟 | 手敲一段 → 跑通 → 理解为什么 |
| 📝 收尾 | 20 分钟 | Git 提交 + 投 3 家简历 + 写 3 行笔记 |

**三条铁律：**
1. 一次只做一条线
2. **SQL 必须合上答案重写一遍** —— 看懂 ≠ 会写
3. 每天必须提交 Git + 投简历

## 七、每周检验标准

**别只看"学完了"，要看"能不能做出来"：**

| 周 | 我怎么考你 | 通过标准 |
|---|---|---|
| 1 | 给你一道没见过的留存题 | 能自己说出要澄清哪 5 个问题 |
| 2 | 给你一个业务场景 | 能设计 3 层指标体系 + 判断 AB 实验可信度 |
| 3 | 全真模拟面试 | 项目讲解不卡壳 + 业务题能拆 + SQL 能写 |

## 八、优先级（时间不够时按这个砍）

```
P0  SQL 基础 + 窗口函数        ← 笔试硬门槛，砍不掉
P0  业务：留存/归因/AB 实验     ← 面试成败
P0  项目讲解（20 分钟不卡壳）   ← 必问
P1  简历 + 投递                ← 没有面试就没有一切
P2  项目代码手敲               ← 加分项，砍到 5 段也够
P3  高级统计（贝叶斯等）        ← 初中级岗不考
```

**如果某天只有 1 小时：只做 SQL 1 题 + 项目复述 1 遍。**
